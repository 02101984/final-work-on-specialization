
1 Использование команды cat в Linux
- Создать два текстовых файла: "Pets"(Домашние животные) и "Pack animals"(вьючные животные), используя команду `cat` в терминале Linux.
В первом файле перечислить собак, кошек и хомяков. Во втором — лошадей, верблюдов и ослов.

nataliya@nataliya-VirtualBox:~$ mkdir final_work
nataliya@nataliya-VirtualBox:~$ cd final_work
nataliya@nataliya-VirtualBox:~/final_work$ cat > Pets.txt
Fido, Dog, 2020-01-01, (Sit, Stay, Fetch)
Whiskers, Cat, 2019-05-15, (Sit, Pounce)
Hammy, Hamster, 2021-03-10, (Roll, Hide)
Buddy, Dog, 2018-12-10, (Sit, Paw, Bark)
Smudge, Cat, 2020-02-20, (Sit, Pounce, Scratch)
Peanut, Hamster, 2021-08-01, (Roll, Spin)
Bella, Dog, 2019-11-11, (Sit, Stay, Roll)
Oliver, Cat, 2020-06-30, (Meow, Scratch, Jump) nataliya@nataliya-VirtualBox:~/final_work$ 

nataliya@nataliya-VirtualBox:~/final_work$ cat > Pack_animals.txt
Thunder, Horse, 2015-07-21, (Trot, Canter, Gallop)

2 Работа с директориями в Linux
 - Создать новую директорию и переместить туда файл "Human Friends".

nataliya@nataliya-VirtualBox:~/final_work$ mkdir finalDZ

 3. Работа с MySQL в Linux. “Установить MySQL на вашу вычислительную машину ”
- Подключить дополнительный репозиторий MySQL и установить один из пакетов из этого репозитория.

nataliya@nataliya-VirtualBox:~$  sudo wget https://dev.mysql.com/get/mysql-apt-config_0.8.32-1_all.deb
[sudo] password for nataliya: 

nataliya@nataliya-VirtualBox:~$  sudo dpkg -i mysql-apt-config_0.8.32-1_all.deb

nataliya@nataliya-VirtualBox:~$ sudo apt-get update 

nataliya@nataliya-VirtualBox:~$ sudo apt-get install mysql-shell
